# Журнал решений и бэклог апгрейдов

Здесь [`richard`](../../.claude/agents/richard.md) фиксирует каждое завершённое
решение — чтобы следующая итерация начиналась не с нуля, а с накопленного опыта.
Без записи сюда работа не считается завершённой (шаг 7 рабочего цикла Ричарда).

## Формат файла

Имя: `YYYY-MM-DD-<slug>.md` (напр. `2026-07-23-email-serial-orders.md`).

Содержимое:

```md
# <Задача> — <дата>

## Задача и контекст
Что решали, для кого, канал/формат.

## Итоговая оценка
NN/100 (грейд) через hard-critic / /judge. Прошли гейт: да/нет.

## Сработавший микс
1. [инструмент] — зачем — что дал
2. …
Почему именно такой порядок/состав.

## В базу знаний
Что добавить в `knowledge-base/`, чтобы следующий раз был сильнее.

## Бэклог апгрейдов v2
- [ ] Конкретная идея, как поднять результат ещё выше
- [ ] …
```

Записи копятся в хронологическом порядке. Периодически переноси повторяющиеся
выводы из `solutions/` в основную базу знаний, чтобы они применялись по умолчанию.
